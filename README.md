# F1 한국어 캘린더

F1 공식 구독 일정을 한국어로 간결하게 정리한 비공식 캘린더입니다. 연습 주행부터 예선, 스프린트, 결승까지 한곳에서 확인할 수 있습니다.

**[구글 캘린더에 바로 추가하기][calendar-google]** · [한국 시간으로 웹에서 보기][calendar-web] · [다른 캘린더 앱용 ICS 구독 주소][calendar-ics]

## 구독하기

1. **[구글 캘린더에 바로 추가하기][calendar-google]**를 열고, 사용할 Google 계정으로 로그인해 추가를 완료합니다.
2. 구글 캘린더의 표시 시간대를 **대한민국 / 서울**로 설정하면 한국 시간으로 볼 수 있습니다. 위 웹 보기 링크는 한국 시간으로 열립니다.
3. 알림을 원하면 해당 캘린더 설정에서 이벤트 알림을 **1시간 전**으로 지정하고 기기와 앱의 알림을 허용합니다.

다른 캘린더 앱에서는 위 ICS 주소를 **URL 구독**으로 추가하세요. 파일을 내려받아 한 번 가져오기만 하면 이후 변경 사항이 자동 갱신되지 않습니다.

## 일정 읽는 방법

제목은 `[G] 일본 GP`처럼 표시하며, 장소에는 `일본 · 스즈카 서킷`처럼 국가와 서킷명을 함께 적습니다. 일정 설명에서 F1 공식 경기 또는 시즌 일정 페이지를 열 수 있습니다.

| 코드 | 세션 |
| --- | --- |
| P1 · P2 · P3 | 연습 주행 1 · 2 · 3 |
| Q | 예선 |
| SQ | 스프린트 예선 |
| S | 스프린트 |
| G | 결승 레이스 |

프리시즌 테스트, F2·F3·F1 Academy, 홍보 일정은 포함하지 않습니다.

## 시간과 알림

- 일정은 한국 시간대를 기준으로 제공하지만, 내 화면의 표시 시간은 사용하는 캘린더와 기기의 시간대 설정을 따릅니다.
- 알림은 구독자마다 직접 설정합니다. 운영자의 알림 설정이 구독자에게 그대로 적용되지는 않습니다.
- 시간이 미정인 일정은 `[G] ⏳ 일본 GP`처럼 대괄호와 이름 사이에 **⏳**를 붙여 종일 일정으로 표시합니다. 시간이 확정되면 ⏳가 사라지고 같은 일정에 시작·종료 시각이 반영됩니다.
- 종일 일정의 날짜는 원본의 예정일입니다. 확정된 한국 시간으로 변환하면서 날짜가 바뀔 수도 있습니다. 종일 일정 알림은 별도로 설정할 수 있습니다.
- 날짜까지 미정인 일정은 날짜가 제공된 뒤 표시됩니다.

## 일정 변경과 다음 시즌

공식 원본의 변경 사항을 매시간 확인해 반영합니다. 시작 시간이 바뀌면 갱신하고, 취소되거나 원본에서 제거된 예정 일정은 삭제합니다. 실제 반영까지는 원본 제공과 사용하는 캘린더 앱의 갱신 주기에 따른 지연이 있을 수 있습니다.

원본에서 **`CALLED OFF`(취소됨)**로 표시한 일정은 이 캘린더에 표시하지 않습니다. **⏳는 시간 미정**을 뜻하며 취소와는 다릅니다. 구독 원본과 F1 웹사이트의 상태가 다를 수도 있으므로, 대회 개최 여부는 공식 경기 페이지와 공지를 함께 확인해주세요.

2026년 이후 일정과 함께, 다음 시즌도 같은 공식 원본에 추가되면 자동 반영합니다. 미정 일정은 추후 바뀔 수 있으므로 경기 전에는 일정 설명의 공식 링크도 확인해주세요.
